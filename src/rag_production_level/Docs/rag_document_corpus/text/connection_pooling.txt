Database Connection Pooling Notes

The platform uses pooled PostgreSQL connections. Pool settings are configured per service
instance. MAX_POOL_SIZE defaults to 50 in production. MIN_POOL_SIZE is 5.

A connection must be returned to the pool after each operation. Long-running transactions
reduce pool availability and can cause request timeouts.

When diagnosing connection exhaustion, inspect active connections, pool wait time, and
transaction duration. Increasing MAX_POOL_SIZE is not a universal fix because PostgreSQL
also has a finite connection capacity.

DatabaseService.cs demonstrates the intended context-managed access pattern.
