Nexus API Error Handling

400 Bad Request:
The request is syntactically invalid or fails basic validation.

401 Unauthorized:
The access token is absent, expired, malformed, or rejected.

403 Forbidden:
The caller is authenticated but lacks the required role.

404 Not Found:
The requested document or processing job does not exist.

409 Conflict:
Optimistic concurrency detected a stale version.

429 Too Many Requests:
The caller exceeded a rate limit.

500 Internal Server Error:
An unexpected server-side error occurred. The API returns a correlation request_id,
which operators can use to trace the request.

Clients should retry 429 and selected 5xx responses with exponential backoff. Clients should
not blindly retry 400, 401, 403, or 409.
